Mart402 provides pay‑per‑call AI‑agent APIs covering document and web extraction, Japanese statutory calculations, and calibrated vision services. No signup or API key is required; payments are made via x402 (USDC on Base). The platform offers free sandbox access on mart402.dev and transparent pricing per call. Services include OCR, PDF parsing, payroll tax calculations, and nutrition analysis from images.

**Areas:** AI · Payments · Japan · Vision · Document
